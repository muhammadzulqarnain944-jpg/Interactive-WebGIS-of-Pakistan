About This Application

This application was developed using HTML, CSS, JavaScript, Leaflet and GeoJSON. It fulfills the main requirements of the Web GIS lab assignment by providing two base maps, two GIS layers, feature attributes, popups and layer controls.

OpenStreetMap and Satellite Imagery
