INTERACTIVE WEB GIS OF PAKISTAN - LAB ASSIGNMENT NO. 1

Files:
index.html
style.css
script.js
data/cities.geojson
data/weather_stations.geojson

Run:
1. Open the folder in VS Code.
2. Install Live Server if needed.
3. Right-click index.html and choose Open with Live Server.
4. Do not open the HTML directly with file:// because fetch() loads the GeoJSON files.

Requirements covered:
- OpenStreetMap
- Satellite imagery
- 15 cities
- 15 weather stations
- City attributes: Name, Province, Type
- Station attributes: Name, Province, Type, Temperature, Rainfall, Wind Speed
- Popups
- Layer control
- Zoom and pan
- Turn layers on/off
- Custom header, map, marker symbols, popup information and page title

Note: Weather values in the included GeoJSON are demonstration values for the lab application. Replace them with an instructor-required observed dataset if necessary.
